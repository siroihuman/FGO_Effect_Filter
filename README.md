# FGO Effect Filter

@wiki「siroi_human」向けの、FGOサーヴァントのスキル・宝具・クラススキル・特性検索ツールです。

- 対象Wiki: https://w.atwiki.jp/siroi_human/
- 特性分類参考: https://w.atwiki.jp/siroi_human/pages/427.html
- Author: argyi
- Version: 1.3.4

## @wikiへの設置

検索ページを「管理者のみ編集可能」に設定し、本文へ次の1行を記述してください。

```text
#include_js(https://cdn.jsdelivr.net/gh/siroihuman/FGO_Effect_Filter@91a78b1b9046b33ed30028d3e03968be77574055/Ra_FGOEffectFilter.js)
```

`@main` はCDNキャッシュにより更新が遅れる場合があるため、動作確認済みコミットを直接指定します。
更新後は「データ更新」を1回押してください。

## 主な検索条件

- スキル・宝具・クラススキル効果
- 効果ごとの倍率（以上 / 以下 / 一致）
- 効果のAND / OR
- 対象（自身、味方単体、味方全体、敵単体、敵全体）
- クラス
- レアリティ
- サーヴァント特性（複数選択、AND / OR）
- 保有スキル / 宝具 / クラススキル
- サーヴァント名
- 検索結果を「スキル上位3つ・宝具上位1つのみ表示」に制限するオプション

## 特性検索

- 個別ページの「特性」欄を自動取得します。
- 特性候補は「各特性持ち編集」ページ上の素の特性リンク名を読み取り、そのカテゴリに従って分類します。
- カテゴリ表示は次の5行×2カテゴリで常に固定します。
  - 基本 / 属性
  - 通常クラス / Exクラス
  - クラススキル１ / クラススキル２
  - 通常特性１ / 通常特性２
  - 特殊特性１ / 特殊特性２
- 「ヒト科以外」は「ヒト科」と同じカテゴリへ揃え、必ず直後に表示します。
- 「夏モード」の直後にある括弧内は霊衣名の注記として扱い、特性名には含めません。例: `夏モード（サマーアヴァターラ・サマーロマーナ・夏の鬼退治）` → `夏モード`。
- 「霊衣を持つ者」の直後にある括弧内も霊衣名の注記として扱い、特性名には含めません。例: `霊衣を持つ者（カルナーヴァレ・タキトゥム）` → `霊衣を持つ者`。
- 上記2特性は括弧内の内容に関係なく基本特性名へ統合し、特殊特性２として扱います。
- 「四季・春」は検索候補・検索結果から除外します。
- 再臨段階で変化する特性は基本特性名で検索し、結果に適用段階を注記します。
