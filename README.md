# FGO Effect Filter

@wiki「siroi_human」向けの、FGOサーヴァントのスキル・宝具・クラススキル・特性検索ツールです。

- 対象Wiki: https://w.atwiki.jp/siroi_human/
- Author: argyi
- Version: 1.2.0

## @wikiへの設置

検索ページを「管理者のみ編集可能」に設定し、本文へ次の1行を記述してください。

```text
#include_js(https://cdn.jsdelivr.net/gh/siroihuman/FGO_Effect_Filter@f586456dc8f8ffa6c61bfcd0d609889b5e3b3692/Ra_FGOEffectFilter.js)
```

`@main` はCDNキャッシュにより更新が遅れる場合があるため、動作確認済みコミットを直接指定します。

更新後は画面上の「データ更新」を1回押してください。個別サーヴァントページから保有スキル・宝具・クラススキル・特性を読み取り、ブラウザへ24時間キャッシュします。

詳細は `ATWIKI_INSTALL.txt` を参照してください。

## 主な検索条件

- スキル・宝具・クラススキル効果
- 効果ごとの倍率（以上 / 以下 / 一致）
- 効果のAND / OR
- 対象（自身、味方単体、味方全体、敵単体、敵全体）
- クラス
- レアリティ
- サーヴァント特性（複数選択、AND / OR）
- 保有スキル / 宝具 / クラススキル
- サーヴァント名

## 特性検索

個別ページの「特性」欄を自動読取し、`/` 区切りの各特性を検索候補として生成します。

例：

- サーヴァント
- 性別不明
- 混沌
- 悪
- 地の力
- 人の力
- 神性
- 領域外の生命
- 人類の脅威
- クトゥルフ

候補検索欄で特性名を絞り込み、チェックボックスで複数選択できます。「選んだ特性をすべて持つ（AND）」と「いずれかを持つ（OR）」を切り替えられます。検索結果にも各サーヴァントの特性を表示し、検索条件として選択した特性を強調表示します。

## 検索結果表示

- ヒットした保有スキル / 宝具 / クラススキルの名称を表示
- ヒットした能力について全効果を表示
- 効果は1効果ごとに改行
- 各効果の倍率・効果値を表示
- 検索条件として指定した効果行を強調表示
- サーヴァントの特性一覧を表示
- 検索条件として指定した特性を強調表示
