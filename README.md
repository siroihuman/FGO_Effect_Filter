# FGO Effect Filter

@wiki「siroi_human」向けの、FGOサーヴァントのスキル・宝具・クラススキル効果検索ツールです。

- 対象Wiki: https://w.atwiki.jp/siroi_human/
- Author: argyi
- Version: 1.1.1

## @wikiへの設置

検索ページを「管理者のみ編集可能」に設定し、本文へ次の1行を記述してください。

```text
#include_js(https://cdn.jsdelivr.net/gh/siroihuman/FGO_Effect_Filter@fcf68e035a2111f33ac6ca6de5efcbd5fb9befda/Ra_FGOEffectFilter.js)
```

`@main` はCDNキャッシュにより更新が遅れる場合があるため、動作確認済みコミットを直接指定します。

初回は画面上の「データ読込」を押してください。個別サーヴァントページから保有スキル・宝具・クラススキルを読み取り、ブラウザへ24時間キャッシュします。

詳細は `ATWIKI_INSTALL.txt` を参照してください。

## 主な検索条件

- スキル・宝具・クラススキル効果
- 効果ごとの倍率（以上 / 以下 / 一致）
- AND / OR
- 対象（自身、味方単体、味方全体、敵単体、敵全体）
- クラス
- レアリティ
- 保有スキル / 宝具 / クラススキル
- サーヴァント名

## 検索結果表示

- ヒットした保有スキル / 宝具 / クラススキルの名称を表示
- ヒットした能力について全効果を表示
- 効果は1効果ごとに改行
- 各効果の倍率・効果値を表示
- 検索条件として指定した効果行を強調表示

## 開発中: 総合検索

既存の効果検索と特性検索を統合する開発を進めています。

現在の統合開発版では以下まで実装済みです。

- `Ra_FGOUnifiedFilter.js` 1本で効果検索・特性検索を同一ページへ起動
- 上部の「統合データ読込」1回で両方のデータ読込を実行
- `Ra_FGOSharedFetch.js` で同じ個別ページの取得結果を共有し、重複アクセスを削減
- `Ra_FGODataCore.js` でサーヴァント一覧取得・個別ページ取得・共通キャッシュ処理を提供
- `Ra_FGOTraitFilterCore.js` で特性検索を共通基盤へ移行
- `Ra_FGOUnifiedData.js` で特性データと既存効果検索の保存データを結合
- 1騎につき `id / name / className / rarity / url / traits / effects` を持つ統合キャッシュを生成

特性の正本は各サーヴァント個別ページの「特性」欄です。「各特性持ち編集」ページは特性データの正本には使用せず、表示順の参考としてのみ使用します。

開発版の設置・確認手順は `ATWIKI_UNIFIED_TEST.txt` を参照してください。
