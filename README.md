# FGO Effect Filter

@wiki「siroi_human」向けの、FGOサーヴァントのスキル・宝具・クラススキル・特性検索ツールです。

- 対象Wiki: https://w.atwiki.jp/siroi_human/
- 特性分類参考: https://w.atwiki.jp/siroi_human/pages/427.html
- Author: argyi
- Version: 1.3.0

## @wikiへの設置

検索ページを「管理者のみ編集可能」に設定し、本文へ次の1行を記述してください。

```text
#include_js(https://cdn.jsdelivr.net/gh/siroihuman/FGO_Effect_Filter@fcb11084b99e59dfc84a28d0ba7ca5fa874fdad4/Ra_FGOEffectFilter.js)
```

`@main` はCDNキャッシュにより更新が遅れる場合があるため、動作確認済みコミットを直接指定します。

更新後は「データ更新」を1回押してください。個別サーヴァントページから保有スキル・宝具・クラススキル・特性を再取得します。

## 主な検索条件

- スキル・宝具・クラススキル効果
- 効果ごとの倍率（以上 / 以下 / 一致）
- 効果のAND / OR
- 対象（自身、味方単体、味方全体、敵単体、敵全体）
- クラス
- レアリティ
- サーヴァント特性（複数選択、AND / OR）
- 保有スキル / 宝具 / クラススキル
- サーヴァント名

## 特性検索

- 個別ページの「特性」欄を自動取得します。
- 特性候補のカテゴリと並び順は「各特性持ち編集」ページを読み取り、その構成を参考に自動生成します。
- 「各特性持ち編集」にない個別特性は「その他・個別」にまとめます。
- 再臨段階によって変化する特性は、検索上は基本特性名で扱います。
- 例: `人型（第一・第二段階）` は「人型」で検索でき、結果には `※ 第一・第二段階` と表示します。
- 例: `超巨大（第三段階）` は「超巨大」で検索でき、結果には `※ 第三段階` と表示します。

## 検索結果表示

- ヒットした保有スキル / 宝具 / クラススキルの名称
- ヒットした能力の全効果
- 各効果の倍率・効果値
- 検索条件に指定した効果行の強調
- サーヴァントの全特性
- 選択した特性の強調
- 再臨段階限定の特性には適用段階を注記
