# FGO Effect Filter

@wiki「siroi_human」向けの、FGOサーヴァントのスキル・宝具・クラススキル効果検索ツールです。

- 対象Wiki: https://w.atwiki.jp/siroi_human/
- Author: argyi
- Version: 1.1.1

## @wikiへの設置

検索ページを「管理者のみ編集可能」に設定し、本文へ次の1行を記述してください。

```text
#include_js(https://cdn.jsdelivr.net/gh/siroihuman/FGO_Effect_Filter@fcf68e035a2111f33ac6ca6de5efcbd5fb9befda/Ra_FGOEffectFilter.js)
```

`@main` はCDNキャッシュにより更新が遅れる場合があるため、動作確認済みコミットを直接指定します。

初回は画面上の「データ読込」を押してください。個別サーヴァントページから保有スキル・宝具・クラススキルを読み取り、ブラウザへ24時間キャッシュします。

詳細は `ATWIKI_INSTALL.txt` を参照してください。

## 主な検索条件

- スキル・宝具・クラススキル効果
- 効果ごとの倍率（以上 / 以下 / 一致）
- AND / OR
- 対象（自身、味方単体、味方全体、敵単体、敵全体）
- クラス
- レアリティ
- 保有スキル / 宝具 / クラススキル
- サーヴァント名

## 検索結果表示

- ヒットした保有スキル / 宝具 / クラススキルの名称を表示
- ヒットした能力について全効果を表示
- 効果は1効果ごとに改行
- 各効果の倍率・効果値を表示
- 検索条件として指定した効果行を強調表示

## 開発中: 特性検索・総合検索統合

特性データは各サーヴァント個別ページの「特性」欄を正本とし、「各特性持ち編集」ページは表示順の参考としてのみ使用します。

現在の統合開発版では以下まで実装しています。

- `/pages/54.html` を起点にサーヴァント一覧を取得
- 個別ページから特性を自動抽出
- 特性AND / OR、クラス、レアリティ、名前検索
- 効果検索と特性検索を1本の `include_js` から起動
- 「統合データ読込」1回で両検索のデータを準備
- 同一個別ページの取得結果を共有可能
- 1騎につき1つの統合データ `id / name / className / rarity / url / traits / effects` を生成
- 統合データを直接利用する「サーヴァント総合絞り込み」UIを追加
- 総合UIで基本条件・特性・効果文言を同時指定可能
- 特性表示順は既存の特性ページを参考にした優先順を維持

開発中モジュール:

- `Ra_FGODataCore.js`: 共通データ取得・統合キャッシュ基盤
- `Ra_FGOSharedFetch.js`: 個別ページ取得共有
- `Ra_FGOTraitFilterCore.js`: 共通基盤版特性検索
- `Ra_FGOTraitOrder.js`: 特性表示順補助
- `Ra_FGOUnifiedData.js`: 効果・特性データ統合ブリッジ
- `Ra_FGOCombinedSearch.js`: 特性・効果を同時指定する総合検索UI
- `Ra_FGOUnifiedFilter.js`: 統合起動用bootstrap
- `data/trait_display_order.txt`: 特性表示優先順
- `docs/INTEGRATION_PLAN.md`: 統合方針

総合検索UIの現段階では、効果条件は効果文言によるAND / OR検索です。既存効果検索にある倍率条件・対象条件・保有スキル / 宝具 / クラススキル範囲指定などは、総合UIの実機確認後に段階的に移植します。

開発版の実機確認手順は `ATWIKI_UNIFIED_TEST.txt` を参照してください。
