# FGO Effect Filter

@wiki「siroi_human」向けの、FGOサーヴァントのスキル・宝具・クラススキル効果検索ツールです。

- 対象Wiki: https://w.atwiki.jp/siroi_human/
- Author: argyi
- Version: 1.1.1

## @wikiへの設置

検索ページを「管理者のみ編集可能」に設定し、本文へ次の1行を記述してください。

```text
#include_js(https://cdn.jsdelivr.net/gh/siroihuman/FGO_Effect_Filter@fcf68e035a2111f33ac6ca6de5efcbd5fb9befda/Ra_FGOEffectFilter.js)
```

`@main` はCDNキャッシュにより更新が遅れる場合があるため、動作確認済みコミットを直接指定します。

初回は画面上の「データ読込」を押してください。個別サーヴァントページから保有スキル・宝具・クラススキルを読み取り、ブラウザへ24時間キャッシュします。

詳細は `ATWIKI_INSTALL.txt` を参照してください。

## 主な検索条件

- スキル・宝具・クラススキル効果
- 効果ごとの倍率（以上 / 以下 / 一致）
- AND / OR
- 対象（自身、味方単体、味方全体、敵単体、敵全体）
- クラス
- レアリティ
- 保有スキル / 宝具 / クラススキル
- サーヴァント名

## 検索結果表示

- ヒットした保有スキル / 宝具 / クラススキルの名称を表示
- ヒットした能力について全効果を表示
- 効果は1効果ごとに改行
- 各効果の倍率・効果値を表示
- 検索条件として指定した効果行を強調表示

## 開発中: 特性検索

`feature/trait-filter-foundation` ブランチで、将来の総合検索への統合を前提とした特性検索モジュールを開発しています。

- 起点は `/pages/54.html` のサーヴァント一覧
- 特性の正本は各サーヴァント個別ページの「特性」欄
- 手入力の「各特性持ち編集」ページは検索データに使用しない
- 特性の複数選択（AND / OR）
- クラス・レアリティ・サーヴァント名との複合検索
- 個別ページの条件付き表記を `raw` / `condition` として保持
- 24時間ローカルキャッシュ
- 将来の統合用に `window.RaFGOTraitFilter` APIを公開

開発中モジュール: `Ra_FGOTraitFilter.js`
