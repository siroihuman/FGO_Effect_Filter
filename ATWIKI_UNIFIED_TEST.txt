Ra_FGOUnifiedFilter 開発版テスト手順
Author: argyi

========================================
1. 設置
========================================
既存の効果検索ページ・特性検索ページとは別のテスト用@wikiページを「管理者のみ編集可能」に設定し、本文へ次の1行だけを記述してください。

#include_js(https://cdn.jsdelivr.net/gh/siroihuman/FGO_Effect_Filter@a4dccf0452a2749cbe94e7480ea8d265cddff4ec/Ra_FGOUnifiedFilter.js)

========================================
2. 今回の確認手順
========================================
1. ページを保存して開く
2. include_js plugin Error が出ないことを確認
3. 「サーヴァント総合検索（統合開発版）」が表示されることを確認
4. 「サーヴァント総合絞り込み」が1画面だけ表示されることを確認
5. 上部の「統合データ読込」を1回押す
6. 「統合読込完了：145騎 / 特性 145 / 効果 145 ...」相当が表示されることを確認
7. 総合絞り込み側が「統合データ：145騎 読込済み」になることを確認
8. 特性一覧が指定済みの優先順で表示されることを確認
9. 効果候補プルダウンが表示されることを確認
10. 効果自由入力でも検索できることを確認
11. 「全能力 / 保有スキル / 宝具 / クラススキル」を切り替えて検索できることを確認
12. 「全対象 / 自身 / 味方単体 / 味方全体 / 敵単体 / 敵全体」を指定できることを確認
13. 倍率・効果値と「以上 / 以下 / 一致」を指定できることを確認
14. 特性＋効果＋クラス＋レアリティ＋名前を同時指定できることを確認
15. 検索結果のサーヴァント名から個別ページを別タブで開けることを確認

========================================
3. 総合検索UIの現段階仕様
========================================
基本条件:
- サーヴァント名
- クラス
- レアリティ

特性:
- 複数選択
- AND / OR
- 特性名絞り込み
- 「各特性持ち編集」ページを参考にした表示順

効果:
- 効果候補プルダウン
- 自由入力
- AND / OR
- 能力種別: 全能力 / 保有スキル / 宝具 / クラススキル
- 対象: 全対象 / 自身 / 味方単体 / 味方全体 / 敵単体 / 敵全体
- 倍率・効果値: 以上 / 以下 / 一致

検索結果:
- 該当騎数
- レアリティ / クラス / サーヴァント名
- 一致した特性
- 一致した効果文言の抜粋

========================================
4. データ読込
========================================
「統合データ読込」は既存効果検索と特性検索のデータを準備した後、1騎につき1つの統合レコードを生成します。

共有ページ 0 / 再利用 0 でも、既存の24時間キャッシュから読み込まれた場合は正常です。

========================================
5. 安全性
========================================
- 既存の効果検索UIはフォールバックとして残しています
- 既存の特性検索UIも残しています
- 詳細条件版総合検索は独立モジュールです
- 旧総合UIは自動的に非表示になります
